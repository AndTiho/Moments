# Moments — веб-приложение для ведения личного дневника

## 📌 Описание проекта

Moments — это веб-приложение для создания и хранения личных моментов.
Пользователь может фиксировать свои ощущения, мысли и воспоминания, дополняя их текстом, изображениями и музыкой.

Проект ориентирован на осознанное проживание текущего момента и бережное сохранение воспоминаний.

---

## ⚙️ Функционал

* Регистрация и авторизация пользователей
* Создание, редактирование и удаление записей (моментов)
* Просмотр:
  * своих записей
  * публичных записей других пользователей
* Детальный просмотр записи
* Поиск по заголовку и содержимому
* Фильтрация по дате (месяц/год)
* Загрузка изображений с автоматической обработкой (сжатие и проверка)
* Возможность добавления музыкальной ссылки

---

## 🧱 Технологии

* Python 3.11+
* Django
* PostgreSQL
* Tailwind CSS + daisyUI
* Docker (поддержка контейнеризации)

---

## 🗂 Структура проекта

* `apps/moment` — логика записей (модели, формы, представления)
* `apps/users` — кастомная модель пользователя и профиль
* `config` — настройки проекта
* `templates` — HTML шаблоны
* `static` — стили и фронтенд

## Подготовка к запуску проекта

### Клонирование репозитория

```
git clone https://github.com/AndTiho/Moments.git
cd Moments
```
  

## 🚀 Установка и запуск (локально через Poetry)

1. Установить Poetry (если не установлен):

```
pip install poetry
```

2. Установить зависимости:

```
poetry install
```

3. Активировать виртуальное окружение:

```
poetry shell
```

4. Создать файл `.env`:

```
SECRET_KEY=your_secret_key
DEBUG=True
POSTGRES_DB=your_db
POSTGRES_USER=your_user
POSTGRES_PASSWORD=your_password
POSTGRES_HOST=localhost
POSTGRES_PORT=5432
```

5. Применить миграции:

```
python manage.py migrate
```

6. Запустить сервер:

```
python manage.py runserver
```

## 🐳 Запуск через Docker Compose

1. Убедитесь, что установлен Docker и Docker Compose

2. Создайте файл `.env` в корне проекта:

```
SECRET_KEY=your_secret_key
DEBUG=True
POSTGRES_DB=your_db
POSTGRES_USER=your_user
POSTGRES_PASSWORD=your_password
POSTGRES_HOST=db
POSTGRES_PORT=5432
```

3. Запустите контейнеры:

```
docker compose up --build
```

4. Откройте в браузере:

```
http://localhost:8000
```

## 📌 Особенности проекта

* Защита доступа: пользователь может редактировать только свои записи
* Валидация: запись не может быть пустой
* Обработка изображений: автоматическое сжатие и проверка
* Разделение публичных и личных записей
* Код соответствует стандартам PEP8 (использовались инструменты форматирования и линтинга)
