# Проект Moments of Your Life
Запиши своё сейчас

## Описание
Проект веб-приложения для ведения личного дневника, как настоящие моменты своей жизни.

**В данный момент находится в разработке, просим проявить терпение.**

## Установка:
1. Клонируйте репозиторий:
```
https://github.com/AndTiho/Moments.git
```
2. Установите зависимости:
```
poetry install
```
## Использование
**Здесь будет информация чуть позже**

В **"Detail view"** мир не исчезает — он становится тише, чтобы момент мог быть услышан.

## Запуск и ожидаемое поведение программы
Для запуска проекта воспользуйтесь:
```
docker compose up --build 
```
Программа находится на стадии разработки.

## Тестирование:
Наш проект покрыт юнит-тестами unit-test. Для их запуска выполните команду:

```
python manage.py test .
```
